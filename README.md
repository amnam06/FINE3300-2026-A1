# FINE3300 Assignment 1: Exchange Rate Calculator

## Project Description
For this assignment, I created a currency converter in Python that uses exchange rate data from the Bank of Canada to convert between CAD and USD. The program reads the exchange rate from a CSV file and uses the most recent rate to calculate the converted amount.

## Part 1: Exchange Rate Calculator
For the first part of the assignment, I created a class called "ExchangeRates" that reads the exchange rate data from a CSV file. The program asks the user to enter an amount, the currency they are converting from, and the currency they want to convert to. It then calculates the conversion and displays the converted amount.

The program allows users to convert from USD to CAD or CAD to USD using the latest exchange rate in the file

## Part 2: AI-Generated Exchange Rate Calculator
For the second part, I used Copilot to create a currency converter. The AI-generated code was saved as "ExchangeRatesAI.py" and tested to check whether it gave the correct results.

I then compared both programs to see how were different.

## Files
- ExchangeRates.py - The currency converter I made for Part 1
- ExchangeRatesAI.py - The version generated using Copilot
- BankOfCanadaExchangeRate.2026.csv - The CSV file containing the exchange rate data
- README.md - An overview of the project

## How to Run the Program
1. Open the assignment folder in Visual Studio Code
2. Make sure Python is installed
4. Run ExchangeRates.py or ExchangeRatesAI.py
5. Enter the amount and currencies when prompted
6. View the converted amount displayed by the program
